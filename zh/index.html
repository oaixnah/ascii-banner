ASCII 艺术字 FAQ。

把 Banner 放进等宽环境之前，需要了解的字符支持、对齐和隐私信息。

什么是 FIGlet 字体？

FIGlet 字体是一种用较小 ASCII 字符组成大型字母的纯文本格式。每种字体都会定义字母的形状、高度和间距。

可以直接生成中文艺术字吗？

暂时不可以。当前 FIGlet 字体库主要包含英文、数字和标准 ASCII 标点。中文版本提供完整中文界面和使用指南，但生成内容仍需使用 ASCII 字符。

怎样让 ASCII Banner 在 README 中保持对齐？

请把结果放进 Markdown 围栏代码块。生成器的 Markdown 复制选项会自动添加代码围栏，让 GitHub 使用等宽字体并保留空格和换行。

输入内容会上传吗？

不会。字体加载、艺术字生成、筛选和复制都在浏览器本地完成。最近输入只保存在当前浏览器，可逐项删除、在生成器中清空，或随网站数据一起移除；网站不会上传输入内容或将其加入分析事件。
