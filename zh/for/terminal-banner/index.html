终端与 MOTD ASCII Banner

设计适合真实终端宽度的 ASCII 欢迎 Banner，让它在 SSH、Shell 和服务器控制台中保持清晰。

为什么使用文本 Banner？

终端 Banner 可以在用户运行命令之前标明主机、环境或安全边界。它应该迅速传达上下文，而不是占满整个屏幕。

以 80 列为基准，不要只依赖颜色表达信息，并通过团队使用的最窄 SSH 客户端测试。Standard、Banner3 和 Small 都是可靠的起点。

一个安全的起始模式

printf '%s\n' '  ____  ____   ___  ____'
printf '%s\n' ' |  _ \|  _ \ / _ \|  _ \'
printf '%s\n' ' | |_) | |_) | | | | | | |'

按照最窄连接设计

80 列仍然是实用基准。较长的主机名和环境名称通常更适合紧凑字体，而不是大型展示字体。

让 Banner 具有实际信息

在艺术字后使用普通文本标明环境、负责人或支持方式。生产环境警告不能只依赖 Banner 表达。
