在 GitHub README 中使用 ASCII Banner

创建清晰醒目的 ASCII 项目标题，在 Markdown 中完整保留间距，同时兼顾 README 的可访问性和可维护性。

为什么使用文本 Banner？

ASCII Banner 能让开源项目拥有容易识别的标题，同时不必向仓库加入二进制图片。关键是保持文字简短、字形清晰，并使用代码块保护排版。

建议从 Standard、Slant、ANSI Shadow 或 Small 开始。这些字体在 GitHub 桌面布局和较窄的移动端页面中都比较容易辨认。

一个安全的起始模式

```text
    _    ____  ___
   / \  |  _ \|_ _|
  / _ \ | |_) || |
 / ___ \|  __/ | |
/_/   \_\_|   |___|
```

使用围栏代码块

三个反引号可以保留行首空格和换行。可以添加 text 语言标记，避免语法高亮器为单个标点添加颜色。

保留普通项目标题

ASCII 艺术字属于视觉文本，但不应要求屏幕阅读器和搜索引擎解析它。请在 Banner 上方或下方保留普通 Markdown 标题。
