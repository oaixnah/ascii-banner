The fine print

ASCII banner FAQ.

Everything you need to move a banner from this page into a fixed-width environment without breaking it.

What is a FIGlet font?

A FIGlet font is a plain-text description of large letters made from smaller ASCII characters. Each font controls the shape, height, and spacing of the generated banner.

How do I keep an ASCII banner aligned in a README?

Paste it inside a fenced Markdown code block. The generator’s Markdown copy option wraps the banner for you so GitHub renders it with preserved whitespace and a monospace font.

Does my text leave the browser?

No. Font loading, rendering, filtering, and copying happen locally in your browser. Recent text history is saved only in this browser and can be deleted item by item, cleared in the generator, or removed with site data. It is never uploaded or included in analytics.

Why do some banners wrap?

FIGlet output is measured in terminal columns. Choose a wider target, a compact font, or shorter input when the result needs to fit an 80-column terminal or source file.
